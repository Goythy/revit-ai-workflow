| 亮点 | 说明 |
| :--- | :--- |
| **效率跃升** | 将原本需要 3~5 天的手动修改，缩短至 **25 分钟** 的对话式操作。 |

## 核心资产：Rules（规则）

`rules/revit-global rules.md` 是本项目 **最具价值的核心资产**。它不仅是代码规范，更是一套经过多次实战踩坑后总结的 **AI 强制行为准则**。

### 它解决了哪些关键问题？

| 问题 | 解决方案 |
| :--- | :--- |
| **防止 AI 瞎猜参数名** | 强制要求先询问用户，禁止硬编码参数名。 |
| **超时诊断流程** | 当 Revit 卡顿时，提供标准化的多级诊断决策树，不再盲目等待或重试。 |
| **代码安全模板** | 强制 `try-catch`、单一弹窗输出、事务管理规范，避免数据丢失风险。 |
| **杜绝常见编译错误** | 如 `doc` 与 `document` 变量名冲突、`StringBuilder` 命名空间缺失、PascalCase 变量遮蔽等。 |

> 拥有这套 Rules，相当于给 AI 配了一个"Revit API 资深导师"。它让 AI 的输出质量从一个"实习生"水平，提升到"有多年经验的 Revit 二次开发工程师"水平。

## 快速开始（精简版）

### 前置条件

- Revit 2020 或更高版本
- VS Code
- Node.js（用于运行 MCP Server）

### 安装步骤

```bash
# 1. 安装 Revit 插件
# 下载 mcp-servers-for-revit，将 .addin 文件放置于 Revit Addins 目录

# 2. 安装 MCP Server
npm install -g mcp-server-for-revit

# 3. 配置 VS Code + Cline
# 安装 Cline 扩展，配置 DeepSeek（或其他兼容大模型）的 API Key
```

### 启动与使用

1. **启动服务**：在 Revit 中点击 **Revit MCP Switch** 启动服务。
2. **打开 VS Code** 并激活 Cline 扩展。
3. **开始对话**：在 Cline 中输入你的第一个指令，例如：
   - "帮我统计当前项目中所有墙的类型及数量"
   - "将楼层 1 中所有 400x800 的梁替换为 500x900"

> 详细的图文配置步骤请查看 `docs/installation.md`（持续完善中）。

## 能力边界（三个天花板）

在开始使用前，请务必了解这套工作流 **不能做什么**，以免产生不切实际的预期：

| 天花板 | 说明 |
| :--- | :--- |
| **不能一句话翻模** | 受限于 Revit 的内建类别体系，**无法像在 Blender 中一样生成任意几何体**。AI 只能操作 Revit 已有的类别和参数，无法凭空创造新的几何类型。 |
| **不能执行超复杂单步操作** | 受限于 Revit 的"单次外部事件"机制，**极其复杂的任务需拆分为多个子任务**。例如"翻模一整栋楼"需要分解为"生成轴网 -> 生成标高 -> 生成墙 -> 生成楼板..."等多个步骤。 |
| **不能精准理解模糊描述** | AI 的推理依赖于精确的指令。**可以执行：** "把 Structural 参数改为 true"；**可能无法准确执行：** "让这面墙变成承重墙"这种模糊表达。 |

> **建议：** 将复杂任务拆解为多个清晰的子任务，逐步与 AI 对话完成。每个子任务聚焦于一个明确的目标。
